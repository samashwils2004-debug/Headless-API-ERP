# Repo Connectivity Output

This folder is generated by `python scripts/generate_repo_connection_map.py`.

Files:
- `repo-connection-map.json`: full machine-readable graph across backend, frontend, endpoints, and cross-layer flows.
- `backend-function-map.md`: backend Python function and method connectivity, including route decorators and resolved repo calls.
- `repo-file-map.md`: frontend file map plus frontend -> Next route -> FastAPI handler flows.
- `filtered-overview.mmd`: Mermaid overview focused on the main frontend/backend request paths.

Filters:
- Included: runtime source files in `apps/api/app`, `apps/web/src`, and `apps/web/middleware.ts`
- Excluded: docs, tests, migrations, SQL, package templates, and `node_modules`
